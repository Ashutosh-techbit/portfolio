Responsive personal portfolio website for **Ashutosh Bansal**, built to present frontend-focused work, technical skills, services/experience, and contact information in a clean, animated, mobile-friendly layout.

- https://ashutoshbansal.tech

## Highlights

- Modern single-page portfolio UI with responsive design
- Sections for introduction, skills, featured projects, and services/experience
- Contact options (email, GitHub, LinkedIn) and contact form integration
- Scroll-triggered animations and polished interactive elements
- Dynamic GitHub stats integration

- HTML

- JavaScript

## Local Setup

This is a static website and can be run locally without a build step.

1. Clone the repository:
   ```bash
   git clone https://github.com/Ashutosh-techbit/portfolio.git
   cd portfolio
   ```
2. Open `index.html` directly in your browser, or serve it with a simple static server:
   ```bash
   python -m http.server 8000
   ```
3. Visit `http://localhost:8000`.
